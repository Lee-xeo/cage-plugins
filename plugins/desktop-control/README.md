# desktop-control

让 Claude 查看这台电脑的屏幕，并使用鼠标和键盘。目前只支持 macOS。

## 工具

| 工具 | 作用 |
| --- | --- |
| `screenshot` | 拍下主屏幕。其余工具的位置都以这张图的像素为准 |
| `click` | 在指定位置单击、双击或三击，可选左、右、中键 |
| `move_pointer` | 移动指针，不点击 |
| `drag` | 按住左键从一处拖到另一处 |
| `scroll` | 在指定位置滚动，按行计 |
| `type_text` | 向当前有键盘焦点的地方输入文字 |
| `press_key` | 按一个键或组合键，如 `return`、`cmd+c`、`ctrl+shift+tab` |

## 使用前

第一次调用时，系统会要求授权。在「系统设置 → 隐私与安全性」里，为运行本插件的应用打开：

- **录屏与系统录音**：截图需要。打开后要重新启动该应用。
- **辅助功能**：鼠标和键盘操作需要。

## 须知

- 截图会把屏幕上当时显示的一切交给模型，包括其他应用的窗口和通知。调用前请留意屏幕上有什么。
- `type_text` 经剪贴板粘贴文字，这样输入法不会改写内容。原先剪贴板里的文字会在之后放回；图片、文件等非文字内容不会保留。
- 只处理主屏幕。
- 只用到 Python 标准库和系统自带的框架，不需要安装依赖。

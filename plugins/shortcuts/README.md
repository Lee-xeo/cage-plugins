# shortcuts

让 Claude 运行你在 macOS「快捷指令」App 里准备好的快捷指令，并读回它输出的文字。只支持 macOS（需要 macOS 12 或更新版本自带的 `shortcuts` 命令），不依赖第三方程序。

## 只开放一个文件夹

插件只能看到、只能运行快捷指令 App 里**一个文件夹**中的快捷指令，文件夹名为 `Claude-Cage`。其他快捷指令对 Claude 不可见。

使用前，在快捷指令 App 的侧栏新建这个文件夹，再把想交给 Claude 的快捷指令移进去。文件夹不存在时，插件不列出任何快捷指令（系统的 `shortcuts list --folder-name` 在文件夹不存在时会列出全部快捷指令，插件在列出前后都会确认文件夹存在）。

## 工具

| 工具 | 作用 |
| --- | --- |
| `list_shortcuts` | 列出该文件夹中的快捷指令，每行一个，格式为 `名称 (标识符)` |
| `run_shortcut` | 运行其中一个快捷指令，返回它输出的文字。`shortcut` 填名称或标识符，同名时须用标识符；可选的 `input` 是交给快捷指令的文字（最多 64 KB） |

`run_shortcut` 按标识符运行，名称或标识符不在该文件夹中时直接拒绝。快捷指令的输出以纯文本（`public.plain-text`）取回，最多返回 1 MB；没有文字输出时会说明。

让快捷指令接收输入：在快捷指令详情里打开「接收输入」并勾选「文本」，在动作中使用「快捷指令输入」变量。返回结果：最后一个动作用「停止并输出」。

## 运行限制

单个快捷指令运行超过 120 秒会被终止。需要使用其他文件夹名或超时时，可在启动 Cage 的环境中设置 `SHORTCUTS_FOLDER`（文件夹名）和 `SHORTCUTS_TIMEOUT`（秒，范围 5～600）。

## 权限与数据

清单声明 `commands`：插件通过 `/usr/bin/shortcuts` 运行快捷指令，快捷指令能做什么取决于你如何编写它（例如发送信息、修改提醒事项或运行脚本）。只把你愿意交给 Claude 的快捷指令放进该文件夹。

传给快捷指令的输入写入系统临时目录中仅本用户可读的临时文件，运行结束后与输出文件一起删除。插件不联网，不保存任何内容。
